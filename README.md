Extract to /addons/

then load it in game with /addon load blulearn

Hold shift while targetting a mob for a UI pop up to show the spell and the level you can learn it.


then type /blul help


Commands: 

/blul list - Shows a list of all learnable 75 era blue spells and what family teaches them
/blul always - shows the pop up always instead of holding shift
